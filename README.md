# printsi agent plugins

The [printsi](printsi/) plugin for agent hosts that support portable Agent Plugins (Hermes Agent, for one): check a
print-ready PDF for free, then have it professionally printed and delivered.

![printsi: IRL prints, ordered by Hermes](docs/banner.png)

See [printsi/README.md](printsi/README.md) for what it does, what it needs and what to know before installing.
